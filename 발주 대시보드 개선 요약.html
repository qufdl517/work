발주 대시보드 개선 요약

데이터 기반 수요 예측 및 업무 자동화 시스템 구축 내역

📈 1. 수요 예측 및 발주 기준 자동화

  • 최근 30일/60일/90일 평균 및 전년도 다음 달 데이터를 비교하여, 최대 소모량을 기준으로 발주 시점 수량을 자동 산출
  • 예상 수요 대비 현재 소모량의 증감 추이를 분석하여 직관적인 시즌성 알림(예: 급증/급감 예상)을 제공

🛡️ 2. 발주 수량 보정 및 안전장치

  • 산출된 순수 부족 수량을 자재별 최소주문수량(MOQ) 및 포장 단위(PLT/Box) 배수에 맞추어 자동으로 올림 보정
  • 담당자가 발주 수량을 수동으로 기입하는 경우에도, 지정된 물류 단위에 어긋나지 않도록 최종 수량을 자동 재보정하여 휴먼 에러를 방지

⏱️ 3. 발주 시뮬레이션

  • 최종 확정 발주량을 기준으로 가용 재고의 사용 가능 일수를 실시간으로 산출하여 담당자의 의사결정을 지원

🚀 4. Apps Script 기반 외부 시트 연동 (PO List)

  • 대시보드 내 체크박스 선택 후 버튼 클릭 시, 최종 발주 내역이 외부 'PO List' 스프레드시트로 자동 전송
  • 데이터 전송 시 'PO List' 내 진짜 마지막 행을 자동으로 스캔하여 입력하며, 기존에 설정된 수식(자재명, 단가 등)이 손상되지 않도록 필수 데이터만 안전하게 기입
